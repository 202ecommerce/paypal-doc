# Documentation fonctionnelle – Module PayPal pour PrestaShop

Ce guide décrit le fonctionnement du module de paiement PayPal pour PrestaShop, à destination des équipes métier, du support et des marchands. Il ne couvre pas l'installation technique ni le code source du module.

## Contenu du guide

- **Moyens de paiement** : les différentes options proposées aux clients selon la version de PrestaShop et le pays
- **Configuration** : réglage du module côté back-office marchand
- **Parcours client** : déroulé du tunnel de commande avec PayPal
- **Remboursements et annulations** : gestion des retours depuis le back-office
